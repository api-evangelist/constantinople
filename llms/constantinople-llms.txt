# Constantinople

> Constantinople (cxnpl.com) is a Sydney-based fintech providing an AI-native
> core-banking platform that lets banks run product, technology, data,
> operations, and compliance as a single modern fabric. It powers retail,
> business, and embedded banking across accounts, payments, cards, lending,
> mortgages, and term deposits. Backed by Prosus Ventures (Series A, A$50M).

This llms.txt was generated by the API Evangelist enrichment pipeline from the
company's public web presence and the API Evangelist catalog. Constantinople's
developer/API surface is a gated B2B platform; there is no public developer
portal, OpenAPI specification, or hosted API reference.
